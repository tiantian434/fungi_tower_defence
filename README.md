# 绘生

一款手绘风格的单人塔防与生长游戏。引导花径延伸，把废弃画作回收为创作能量，建立自己的防线，再在花海中拾回继续创作的勇气。

当前版本：`0.1.0-jam`，Windows 64位。

## 游玩

发布包解压后运行 `Huisheng.exe`，同名 `.pck` 文件需要放在旁边。项目源码使用 Godot 4.7.2，默认启动场景是 `scenes/ui/main_menu.tscn`。

主要操作可以点击工具栏完成，首次事件教学会给出下一步建议。

| 操作 | 作用 |
| --- | --- |
| G | 指定方向，自动延伸花径并形成花朵 |
| B / C | 远处建造 / 在选中花朵上建造 |
| 左键 / 右键 | 选择、确认 / 取消当前操作 |
| Space | 规划暂停或恢复 |
| WASD / 中键拖动 / 滚轮 | 移动与缩放视角 |
| Home | 恢复开局视野 |
| F11 / Alt+Enter | 窗口与无边框全屏切换 |

点击右上角“菜单”可调整音量、显示设置、重开或返回标题。继续游戏从最近解锁章节开头开始，不保存局内布局。

三章目标：第一章守住小画家并完成三次遭遇；第二章关闭三处干扰创作的终端；第三章让连通花海覆盖三处记忆，各累计收集5秒。通关后可以回顾完整记忆、欣赏这次长出的花海，再进入结尾；成绩页可以回看本局花海。

第二章前沿炮台建成后，点击附近的评价终端，让射程内炮台集中攻击它；再次点击可取消优先。关内教学会在首座能覆盖终端的炮台成熟时提示。

## 本轮优化

- 第一章收紧为三段遭遇，固定资源只解锁第一步成长，后续能力需要实际战斗回收。
- 第二章错峰启动终端，逐步增加敌人种类，给回收和前沿建设留出时间。
- 教学提示可直接关闭、自动推进，并优先展示当前进展和危险；两个成长阶段分别教学。
- 回流显示实际获得的能量，成长阶段触发网络脉冲；记忆目标使用三张独立画页。
- 章节入口统一管理未读剧情，兼容旧进度；正式游戏不开放开发场景快捷键。
- 窗口选择在切关后保留，支持全屏；改善小屏布局、建造提示和地图边界。
- 静音后跨场景、重启仍能恢复之前选择的音量。

## 工程与验证

| 入口 | 内容 |
| --- | --- |
| `scenes/levels/` | 三章地图和关卡接线 |
| `scenes/gameplay/colony_gameplay.tscn` | 可在编辑器检查的共用玩法节点 |
| `scripts/gameplay/` | 共用运行、镜头与生命周期 |
| `scripts/ui/` | 教学卡、记忆回顾和成画界面 |
| `resources/first_level_waves/`、`resources/ai/` | 遭遇与生产配置 |
| `resources/story/` | 四段剧情分镜与文字 |
| `scripts/display/`、`scripts/audio/` | 显示和声音设置 |
| `tests/` | 资源、输入、生命周期和正常规则路线验收 |

节点与画面优先在场景中组织；运行脚本负责规则和接线。第一章仍兼容早期演示继承链，发布时不要按文件名包含 `demo` 批量删除依赖。
