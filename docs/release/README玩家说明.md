# 绘生

版本：0.1.0-jam · Windows 64 位 · 单人离线游戏

解压整个文件夹，运行 `Huisheng.exe`。请让同名的 `Huisheng.pck` 与它保存在同一目录。

你是一位重新拿起画笔的小画家。引导路径生长，把废弃的画作变成能量，在自己的花海中寻找继续创作的勇气。

## 开始游玩

从标题选择“开始游戏”。根据关内提示逐步学习；底部工具栏可以完成主要操作，无须记住所有快捷键。“继续游戏”从已解锁的章节开头继续，不保存关卡中途的布局。

- **观察地图：**WASD 或鼠标中键拖动；滚轮缩放；Home 回到小画家。
- **建设与选择：**左键选择对象或确认位置；右键取消当前操作。先沿路径回收资源，再建立新的防线。
- **第二章集火：**前沿炮台建成后，点击附近的评价终端，让射程内炮台优先攻击它；再次点击取消优先。
- **常用工具：**G 延伸花径，B 远处建造，C 在选中的花朵上建造设施；其它操作见工具栏和“帮助”。
- **暂停与设置：**点击右上角“菜单”调整音效、音乐并返回标题；空格切换规划暂停。Esc 关闭菜单或取消当前操作。
- **显示：**F11 或 Alt+Enter 切换窗口与无边框全屏，窗口也可拖动边缘调整大小。
- **剧情：**空格或“继续”翻页，也可以使用剧情界面的暂停和跳过按钮。

三章分别需要保护小画家、关闭干扰创作的终端，以及连接并收集三处记忆。注意顶部当前目标和地图上的提示。

如果画面较拥挤，可以缩小镜头或切换全屏；如果忘记下一步，打开帮助查看当前提示。
